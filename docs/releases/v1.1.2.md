# v1.1.2 功能预览版

桌宠现在可以通过已登录的对应宿主进行对话、碎碎念和用量查询，并提供大小调整与四张乔思伯屏幕背景。

## 已验证的功能

- GPT / Codex：复用本机 Codex 已登录的 ChatGPT 账号，支持桌宠对话、碎碎念、Codex 套餐剩余百分比与重置时间。不是 API 充值余额，也不代表 ChatGPT 所有功能的统一用量。
- DSH：使用当前宿主模型和账号；实测 deepseek-account / deepseek-flash 的桌宠对话及账号余额查询成功。
- 右键“桌宠大小”：50%–200%，每次 10%，支持恢复 100%，每只桌宠分别保存。
- 乔思伯屏幕背景：星空露台、午后花园、暖光书房、日落海岸，支持保存与恢复默认。
- 修复短暂动画断帧后恢复官方程序、造成屏幕重新被占用的问题；实机 USB 持续 streaming，整体顺时针旋转 90°。
- 使用独立在线心跳识别 DSH 大肥鱼与 GPT ChatGPT 娘；两个 GPT agent 不会被当成双人搭档。

## 已知限制

**107 段龙公主动作与 8 组双人 GIF 的动作质量仍未通过用户验收。** 姿势连贯性、形变和边缘质量需要返工。本版本保留素材供测试与替换，不宣称动画质量合格。新的 20 个单人动作与 10 个双人动作目前是设计描述，尚非 30 段已完成动画。

本次为用户明确要求发布的预览版，质量审查记录仍保留 rejected 状态。后续版本仍需重新确认动画验收或单独的预览发布授权。

## 下载与安装

- Windows：下载 pet-trio-windows-x64-lite.zip，解压后双击 install-plugins.cmd，选择 DSH 或 GPT / Codex，在宿主插件列表启用。
- DSH 包安装：使用 pet-trio-windows-x64-lite.tgz；ZIP 与 TGZ 含相同运行文件。
- .sha256 是校验值，.files.json 是文件清单。lite 不包含 Electron、Python 或制作源图；完整播放素材仍较大。

已完成构建、TypeScript 类型检查、桌宠与桥接回归、18 项 Python 屏幕测试和安装工作流测试。两宿主、真实模型回复、套餐窗口、余额、缩放、背景合成和双人身份条件均有本机验证。GitHub Actions 结果以对应提交的检查页面为准。
