# 合并结构与检查范围

根目录是唯一安装、构建与发布入口，`dsh-pet/` 是唯一共享引擎模块，不再分发两套独立桌宠。新提交只引入当前所需源码与素材；原仓库的完整 Git 目录保留在本地归档，避免再把旧二进制历史复制到新仓库。

## 该共用的内容

窗口、物理、右键菜单、状态聚合、下载器、安装器、MCP 桥接和 USB 输出共用。字体、指针和通知图标共用。旧的 `dsh-pet` 包名、用户存储目录、端口 19390、HTTP 前缀 `/dsh-pet-7340` 与桥接 service 标识用于兼容，保留它们不会读回旧盘符。

## 该分开的内容

角色动画与对话配图分别存于 `assets/pets/fish`、`whale`、`chatgpt`，双人素材存 `duo`。`@角色`资源路由不存在时返回 404，不会拿其他角色顶替。三位角色的提示词、固定台词和对话记忆分别选择；原版大肥鱼动作与配图保留。

ChatGPT 娘旧的简单 WebM 动作和展示用 preview.gif 已由实际播放 GIF 替换。源图、参考图、生成提示词移到 `art-source`，不进入轻量包。鲸鱼娘原插图保留在 `art-source/whale/illustrations`，不重复装入运行包。

## 双宿主与并发

桥接协议升级到 4，并检查构建版本；安全迁移本项目旧协议 1/2/3 及同协议旧构建；不终止其他服务或未知更新版。新插件开关精确对应新 marketplace 身份，不与旧独立插件开关串用。多个 MCP agent 各有独立租约与状态；忙碌优先，单个断开不关闭其他会话。

双人模式需要 DSH 与 GPT 同时有存活的独立在线心跳（兼容旧版画面心跳），且分别选中大肥鱼和 ChatGPT 娘、GPT 桌面输出开启。只安装、两个同宿主 agent、角色切换或租约超时都不会误触发。自动轮换八组，也可右键固定动作或关闭；单人 DSH 窗口暂隐，后台心跳不暂停，离线恢复。

屏幕保持先到来源，用户手动切换；屏幕互斥锁防止跨进程争用。默认顺时针90度；整个合成帧包含文字与当前角色配图，一起旋转。

## 验证

- 源码构建、类型检查、共享核心与宿主回归。
- 隔离后台 HTTP 检查角色切换、记忆、配图及 GIF 正确 MIME 和资源边界；不打开桌宠。
- 无头 Chrome 从实际 GIF 解码逐帧验证画布变化、单次结束、停止/释放，并检查乔思伯合成帧变化。
- 安装器回归使用隔离夹具，检查实际安装命令、ZIP/TGZ 清单、SHA256 与文件边界；支持实际注册与安装。
- Windows CI 执行发行包全新运行组件准备和冷启动/重启。本机复用已有组件；本次已实测 JONSBO USB streaming、帧数持续增长及管理员程序接管。双宿主实机结果以最终检查记录为准。

固定版本运行组件仍使用经过 SHA256 锁定的原仓库历史 URL；这些是可追溯依赖来源，不能把它们当旧本机路径批量删除。原作者版权与资源来源保留在 LICENSE 和 THIRD_PARTY_NOTICES.md。

## 原素材完整性

两个旧仓库已跟踪的媒体与字体共 394 项，按 SHA256 逐文件验证；原路径变更仅用于角色归属、共享去重或制作归档。替换的新素材不会覆盖唯一的旧资源。原工程 .archive 目录保持完整，不进入运行包。
