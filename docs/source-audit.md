# 两项目统一检查标准

| 范围 | 处理边界 |
|---|---|
| 分发 | 源码 ZIP、Release 轻量 ZIP、GitHub 链接使用相同安装入口；包内包含预编译代码、三角色素材及双宿主清单 |
| 角色 | 同一桌宠的浏览器和桌面使用同一角色状态；ChatGPT 娘独立台词、提示词和 27 张对话插图，不回退到另一角色图片 |
| 会话 | MCP 每连接独立 session；DSH 每窗口租约独立；结束一个 agent 不终止另一个。模型聊天记录按角色和实例隔离 |
| USB | 两项目故意共用同名屏幕互斥锁；保持当前投屏，另一桌宠等待，可在界面手动接管；整帧包含文字和插图一起顺时针 90° |
| 项目 | package / 插件 ID、端口 19389 / 19390、用户数据目录和默认角色各自独立；不以另一仓库目录作为运行依赖 |
| 路径 | 使用包根和宿主用户目录；移除开发者磁盘路径、Codex 专用 Python / Node 回退路径及失效全量打包入口 |
| 保留 | 三角色当前图片、GIF、WebM、上游许可证和必要配置迁移；不删除用户聊天、密钥、个性配置或有效原版素材 |

两个仓库独立下载即可运行。重复的角色图片和安装脚本属于各发行包所需内容；不建立跨仓库绝对路径。受保护的运行组件地址包含固定提交和 SHA256，属于可重现下载来源，不是旧本机路径。

大肥鱼历史默认“蓝毛小女仆 + both”只在读取时迁移为“大肥鱼 + desktop”；用户明确设置的其他 `both` 保留。旧名称只在此迁移规则及其测试保留。

本地验证使用无显示、禁下载的测试环境；真正首次下载、启动和重启由 Windows CI 执行。宿主插件列表的实际安装 / 启用和 USB 目视验收需要相应宿主与硬件，不以静态包检查冒充实机验收。
