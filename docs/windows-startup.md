# 下载、启动与投屏

本仓库只分发一份插件与一套引擎，包含三位桌宠。使用方式见根目录 README 与 installation.md。

用户双击 install-plugins.cmd 注册到对应宿主的插件列表；独立启动使用 start-pet.cmd，完全停止使用 stop-pet.cmd。启动准备窗口检查缓存、显示下载进度、核验 SHA256、解压并验证组件；无需预装 Node/Python 或让 agent 跑安装命令。

源码 ZIP、浅克隆与轻量 Release ZIP 都含编译产物。轻量包排除开发依赖、运行组件、源图、本机配置及日志。首次启动下载的 Electron 自带 Node 被复用，Python 与 Pillow 用于屏幕工作进程，组件按版本缓存。

DSH 默认是单一桌面显示，用户明确选择 both 才双位置显示。GPT 独立启动默认 ChatGPT 娘，后续右键保存的角色优先。

同一桥接支持 DSH 和 GPT 两个来源、多个 GPT agent 会话。屏幕维持当前来源，由状态页手动切换；两只兼容角色同时在线时，GPT 窗口显示双人 GIF，DSH 单人窗口暂隐。关闭一方就恢复单人。屏幕默认顺时针旋转90度，保留用户已有显式设置。

CI 从轻量包解压到干净目录，在无 Node/Python PATH 下准备组件、检查 MCP 握手和实际输出帧，并验证停止后重启。这个联网冷启动检查只在 CI 执行，本机开发可运行无下载、无桌宠窗口的隔离测试。
