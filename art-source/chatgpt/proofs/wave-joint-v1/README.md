# 龙公主挥手：连续关节动画试作 v1

状态：**试作，未通过用户验收；不接入正式播放，不随 1.1.0 发布。**

原补帧动画因姿势跳变、肢体变形和边缘模糊被用户否决。本样片仅检查固定角色部件的连续运动是否能改善这些问题，不表示已达到原版动画的复杂度。

动作共 9 秒：0–1.4 秒停留，1.4–3.2 秒抬臂，3.2–6.5 秒挥手两次，6.5–8.2 秒收手，最后回到起始姿势。肩、肘、腕由连续曲线控制，头、翼和头发有轻微跟随；没有光流补帧、姿势交叉淡化或整个人物轮廓变形。

素材由内置 image_gen 生成透明拆件图，提示词见 prompt.txt。人物设计参考用户提供的银白发龙公主图片。原作者角色设计权利不因本次试作而转移；项目维护、代码许可及复用来源见仓库 LICENSE 和 THIRD_PARTY_NOTICES.md。

- wave-joint-proof.gif：640×480、9 秒、24fps 编码的透明 GIF。
- contact-sheet.png：六个时刻的外观检查。
- motion.json：动作曲线采样及制作方式。
- encoding.json：文件参数。帧数不代表动作质量合格。
- rig-atlas.png / parts：单张角色拆件图及机械分割结果。

已知局限：表情固定，发丝、裙摆缺少细致变形；拆件接缝和关节路径仍需结合实际播放判断。这段只验证连续性，不能代替完整动作的逐段验收。

本地已有 Playwright、Chrome、Pillow 时可运行 extract-rig.py、render.mjs、encode.py 重新导出；本流程无需下载或启动桌宠。
