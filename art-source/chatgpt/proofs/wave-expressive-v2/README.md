# 挥手表情素材试作

本目录保存本轮 imagegen 生成的面部拆件源图、机械分割的部件、提示词和原版挥手动作抽帧对照。新版完整动作尚未渲染，没有新版 GIF。

face-atlas.png 为面部源图；parts/ 为身体、头发、龙翼、尾巴、手臂和面部部件；parts.json 为分割坐标；prompt.txt 为生成提示词；fish-wave-study.png 为原版大肥鱼挥手抽帧对照。上一版挥手 GIF 与其完整拆件源图在相邻 wave-joint-v1 目录。

这套素材未经质量验收，尚未接入桌宠。角色设计参考用户提供图片；复用资源与代码权利见仓库 LICENSE 和 THIRD_PARTY_NOTICES.md。
